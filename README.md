Entry for the [make.fun](https://make.fun) bounty
[Make the AI Judge Laugh: Cat Reviews Its Human](https://make.fun/c/u-motasimfuad-make-the-ai-judge-laugh-cat-reviews-its-42a34990).

One funny single-line one-star review from a house cat about its human, under 200 characters, deadpan all the way through: late food, an occupied lap, shedding staff.

`main.py` (Python 3) writes the entry to `/output/entry.txt`:

> One star. Food arrives late, the lap is often occupied by a glowing rectangle, and the staff sheds almost as much as I do.

Run it locally with:

```sh
MAKEFUN_OUTPUT_DIR=out python3 main.py
```
